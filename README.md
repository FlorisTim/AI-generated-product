# Reflection

### Product
the product in question was a coding envrioment with a high level language and a low level language,
the idea was that youd be able to draw simple moving images with the language and simple zero player games.

### Reflection
I learned a great deal about what AI is capable of in 2026, but i do recognise some flaws like that when it wrote
the parser for the code it would see the token `"hello world"` as `"hello` and `world"` because it split at whitespaces.
It was interesting to work with AI, sometimes almost scary but alot of the time frustrating because it just wouldnt do something.
AI did stimulate some of my creative process because it would expand on my ideas further.

### Pros of using AI

- Works fast
- Mostly understands what you want
- Is capable of fixing simple bugs

### Cons of using AI

- If it doesnt understand, it does something very weird
- It uses code it can explain only half of the time and uses syntax that's hard to understand for new coders
- It can't apply logical reasoning behind the code it generates to other languages that it didnt get fed (i can't learn it a new language real quick in the chat, even if simple)

### End of reflection

I really did not like using AI, i do like the result and that i got to develop it fully without really having to engage myself,
for me this also has the downside that now i have a finsished product i could explain conceptually but not what's really happening behind the scenes.
